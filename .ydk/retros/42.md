## Analysis (Claude Code session, no API provider)
### What went well
- Tasks ran sequentially, one at a time: #44 (PR #49), #45 (PR #50), #46 (PR #51), #47 (PR #52), #48 (PR #53). Each PR was small and had a small review.
- All gates were green on every PR (GoldenKit 1212/1212).
- The fault-injection seam (`--inject-fault internal_error`, `CheckedExtractor`) was built first in #44. TDD for the guards in #45 and #46 followed from it.
- Stage guards and per-part catches (#45) return a partial result with `internal_error: <stage>: <Type>`. HeaderMapper per-field guards (#46) separate content failures (`metadata_field_failed`) from bugs (`internal_error: metadata.<key>`).

### Friction
- `corpus/internal` is absent on this machine, so the harvest probe acceptance criterion of #48 is unmet. The owner must run `golden probe` elsewhere.
- The pre-commit TDD guard demanded test files for doc-only and XML-doc changes (IEmlExtractorTests.cs added) and forced split tests.
- The guard hook blocks writes under `.ydk/proofs`, so orchestrator progress files could not be written; `ydk task comment` was used instead.
- Stale orchestrator-progress files from earlier runs confused resume detection.
- The GoldenKit score run rewrites `docs/golden-score.txt` with line-ending churn.
- Review leftovers were documented rather than fixed.
- Stale "not implemented" notes in other ADRs were found only at the end (follow-up quick task needed).

### Rule suggestions
- Sweep other ADRs and specs for "not implemented" notes when a task implements the target, in the same PR (repeat of the epic 15 lesson).
- Let the TDD guard exempt doc-only and XML-doc changes.
- Make resume detection ignore progress files from finished runs.
- Normalize line endings when GoldenKit writes `docs/golden-score.txt`.

### Open owner decisions
- The body-stage bug path returns the text body also as an attachment (ADR-026 "owner to confirm").
- A failed metadata key drops the already-mapped raw header value.
- The `internal_error` outcome is detected by scanning warning prefixes, not a typed signal.
- Run `golden probe` on the internal corpus to close #48.

### Summary
Epic 42 made extraction return partial results with `internal_error` warnings instead of throwing, with tests, telemetry and docs aligned (ADR-026). Remaining: the harvest probe run, the three owner decisions, and a stale-note sweep in other ADRs.
