# ADR-018: Committed realistic samples for correctness B; absent samples skip visibly

## Status
Accepted (per project owner, 2026-10-17). Implementation pending, tracked as Stage 02 work. Amends ADR-007 (attachment quality bar) and the "pass vacuously" project rule.

## Context
Correctness B in the brief: Office files, other emails, attached images, and copy-paste inline images. In CI today:
- unit and golden tests use tiny typed stubs (right leading bytes, no real content);
- real Office, `.msg`, and TNEF samples sit only in the gitignored `corpus/internal/`;
- `InternalCorpusTests` return early when a sample is missing, so they report Passed in CI without running anything.

A green CI run therefore says nothing about real attachments.

## Decision
Per project owner, 2026-10-17:
- Commit a realistic sample set under `corpus/realistic/` that CI always runs. It covers: OOXML (`.docx`, `.xlsx`, `.pptx`) and legacy OLE (`.doc`, `.xls`) Office files, PDF, an attached Outlook `.msg` item, an attached `.eml`, a TNEF `winmail.dat` holding an Office file, an attached image, and Outlook-style and Gmail-style pasted inline images.
- Each sample is either a public file whose license allows redistribution (MIT, Apache-2.0, BSD, CC0, CC-BY), or generated by open-source tooling from a committed script.
- `corpus/realistic/manifest.json` records for every sample: file, source URL or generator script, license, SHA-256, and the expected values.
- Expected values (subfile names, sizes, SHA-256, container paths) come from the generator's inputs or the source's published contents, never from extractor output and never from prose. This keeps ADR-007's independence rule.
- Tests over samples that cannot be committed (the gitignored internal corpus) report Skipped, with the missing path, when the sample is absent. They never report Passed without running.

## Alternatives
- Keep stubs plus the local corpus (status quo). Rejected: CI passes trivially.
- Commit the internal corpus. Rejected: licenses vary and samples contain personal data.
- Record expected values from a first extractor run. Rejected: the extractor would be its own oracle (ADR-007).

## Consequences
- New requirement `ydk:req:quality/realistic-attachment-samples` and test spec `ydk:test:quality/realistic-samples.integration`.
- `ydk:test:quality/internal-corpus.integration` changes from vacuous pass to visible skip.
- Every committed sample is listed in `THIRD-PARTY-NOTICES.md` (ADR-017).

## Evidence
`tests/EmlExtraction.Tests/InternalCorpusTests.cs`, `docs/specs/quality.md`, `yoavarad/ole-extractor` sample provenance fields. Project owner decision, 2026-10-17.
